The funniest honest error message an appliance could show, for make.fun's "The Funniest Honest Appliance Error" bounty ($2, winner takes all).

> Error: cliff sensor blocked by dust. I cannot see the stairs because of the dirt I was hired to clean. This is a conflict of interest.

The line lands because it names a real fault — a robot vacuum's optical cliff sensor genuinely gets blocked by dust — and the joke grows out of that truth: the machine hired to remove dirt is blinded by dirt, and it reports the fact as a workplace grievance. Flat, put-upon, and written as if the machine did not mean to be funny.

## Run it

```sh
python3 main.py
```

`main.py` writes the error line to `entry.txt` (honouring `MAKEFUN_OUTPUT_DIR`, default `/output/entry.txt`) and prints it. The line is 134 characters long (135 bytes with the trailing newline), within the 200-character limit.
